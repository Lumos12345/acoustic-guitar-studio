# Acoustic Guitar Studio · 吉他练习台

一个面向木吉他练习者的桌面工具，把练琴时最常用的四件事——**调音、跟节拍、找谱、查和弦**——收进同一个离线应用，并额外提供**自制乐谱**能力。

基于 Electron + 原生 HTML/CSS/JavaScript 开发，单文件便携版双击即用，无需安装、无需联网、不上传任何数据。

## 功能特性

### 调音器
- 麦克风实时拾音，显示音名、频率与音分偏差，指针进入中间区域即为准音
- 支持标准调弦 E A D G B E，以及 Drop D、DADGAD、Open G、Open D 等调弦方案
- 点击琴弦可单独试听该弦标准音
- 采用归一化自相关做基频检测，配合最早强峰选择、抛物线插值与多帧中值滤波，抑制泛音导致的八度误判和指针抖动

### 节拍器
- 40–240 BPM 无级调速，4/4、3/4、2/4、6/8 拍号，每拍 1/2/3/4 细分
- 首拍重音，木鱼、电子咔哒、蜂鸣三种音色，实时合成不依赖音频文件
- 流行、抒情、摇滚、指弹四种节奏预设一键套用
- 连续点击「打拍定速」即可估算 BPM
- 基于 Web Audio 的前瞻调度，避免定时器抖动

### 乐谱库
- 支持拖拽导入 JPG / PNG / WEBP / PDF，一次选多张自动合并为一首曲子的多页图集
- 曲名搜索、重命名、追加页、删除、打开所在文件夹
- 查看器支持翻页、缩放、新标签打开，PDF 由 Chromium 内置阅读器直接渲染
- 数据以「一首曲子一个文件夹」的形式保存在本地磁盘，可直接备份、迁移

### 和弦库
- 12 个根音 × 8 种常用性质（大三、小三、属七、大七、小七、挂四、挂二、六和弦）
- 升号 / 降号切换，按曲风筛选，按根音索引
- 点开可查看指法图、读音、和弦色彩与常用和弦走向
- 支持收藏常用和弦

### 自制乐谱
- 支持「弹唱和弦谱」与「六线指弹谱」两种模式
- 以小节为单位编辑，可填写原调、选调、变调夹、拍号、速度、调号、特殊调弦、难度与备注
- 六线谱支持品位、时值、击弦 / 勾弦 / 滑音 / 推弦 / 颤音 / 泛音、力度、连音线
- 撤销 / 重做、选区循环、示范播放（Web Audio 合成拨弦与扫弦）
- 草稿自动保存，支持 JSON 导入导出与 2 倍分辨率 PNG 导出

## 技术栈

| 部分 | 方案 |
| --- | --- |
| 桌面框架 | Electron 33 |
| 界面 | 原生 HTML / CSS / JavaScript，无前端框架 |
| 音频 | Web Audio API（节拍合成、拨弦与扫弦试听） |
| 绘图 | SVG（和弦图）+ Canvas（乐谱预览与导出） |
| 存储 | 本地文件系统（主进程 IPC） |
| 打包 | electron-builder 25，Windows 便携版 x64 |

安全配置：渲染进程启用 `contextIsolation`，关闭 `nodeIntegration`，文件能力通过 `preload` 白名单暴露。

## 本地运行

```bash
npm install
npm start
```

## 打包

```bash
# Windows 便携版
npm run dist

# Windows 安装包
npm run dist:installer
```

产物输出到 `dist/`，便携版为 `AcousticGuitarStudio-<version>.exe`。

## 数据存储位置

- 程序配置与缓存：`%LOCALAPPDATA%\GuitarStudio`
- 乐谱库：`文档\吉他乐谱库`（可在应用内更换为任意文件夹）
- 每首曲子对应一个文件夹，自制乐谱保存在其中的 `chart.json`

备份时直接复制「吉他乐谱库」文件夹即可。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 开始 / 停止节拍器 |
| `←` / `→` | 减慢 / 加快速度 |
| `Ctrl+Z` / `Ctrl+Y` | 乐谱编辑撤销 / 重做 |

## 项目结构

```
guitar-studio/
├─ main.js            # Electron 主进程：窗口、乐谱库文件读写 IPC
├─ preload.js         # 暴露给渲染进程的最小文件能力
├─ index.html         # 界面结构
├─ styles.css         # 样式
├─ app.js             # 调音器、节拍器、乐谱库、和弦库、乐谱编辑器
├─ scripts/
│  └─ apply-icon.js   # 打包后写入 exe 图标
├─ icon.png / icon.ico
└─ package.json
```
